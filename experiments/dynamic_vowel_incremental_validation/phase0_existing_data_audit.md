The three-system common strict preservation support is 214 matched tokens, with vowel counts AE 55, EH 54, IY 53, IH 52 across 16 speakers. The earlier four-vowel-complete equal-weight summary used 199 tokens/14 speakers. Existing work already calculated trajectory RMSE, centered-shape RMSE, midpoint RMSE, shape gain, center position, displacement-vector error, path length, curvature, temporal asymmetry and five-point mean DID. These are inherited evidence, not new findings.

**Matched dynamic attrition.** Among frozen-PASS pairs, strict five-point QC retains EH 35/39 (11 speakers) and IH 18/56 (9 speakers). Track QC retains EH 39/39 and IH 49/56. The 42 strict pair exclusions consist of EH: `FC_EH_TO_AE_BWC_05`, `FC_EH_TO_AE_LXC_03`, `_04`, `_08`; IH: 38 pairs. The complete per-token list with target ID, pair ID, both durations and exact original/clone reasons is in [qc_attrition_tokens.csv](qc_attrition_tokens.csv), derived without changing any flag from frozen `reconstruction_token_trajectories.csv`. Across 190 original frozen-PASS target tokens, strict duration-out-of-range was flagged 75 times and wider track duration implausibility 8 times; these token flags can overlap within one pair. No new QC cutoff will be chosen from the present results.

**Segmentation and tracking.** Preservation extraction uses source TextGrid phone indices matched to clone MFA TextGrid indices. Segmental matched extraction uses frozen target phone intervals and MFA clone intervals; previous five-point re-extraction uses the same 0.005 s Praat Burg step, 0.025 s window, frozen speaker ceiling and alternate-ceiling formant checks. The tasks do not use identical token selections: preservation covers naturally occurring vowels throughout selected sentences; matched reconstruction covers annotation-defined error/control tokens. Natural baseline tracks use held-out-C originals; cross-utterance natural pairing differs from same-text original/clone pairing. All new calculations use existing five-point tables, so segmentation/tracking rules cannot drift in this phase.

**Inference and feasibility.** Existing NDS is clone–original distance divided by the speaker-by-vowel median among up to 200 deterministic held-out original–original pairs from distinct utterances. Existing canonical projection is `dot(log(F1,F2)-mu_deviation, axis_vector)/||axis_vector||²`, positive toward the frozen speaker-specific canonical endpoint. Existing bootstrap resamples speakers, with tokens nested within them. Strict F5 preservation tracks have 395 tokens/16 speakers. Exact same utterance ID, word index, phone index and vowel occurs for at least two speakers in 60 groups (144 target tokens, max five speakers/group); this permits a restricted cross-speaker control with identical sentence/word/phone context, though realized stress and duration still require checking. A speaker-disjoint vowel-category classifier is possible on the 214 common tokens, but it is secondary and cannot alone establish clone distortion.

**Leakage/claim boundaries.** Split by speaker before feature standardization or model fitting. No target speaker's originals may be used as a cross-speaker reference except in the designated same-speaker condition. Existing axes, QC, NDS and midpoint results remain frozen. Dynamic acoustics do not establish perceptual correction, active reference transfer, or an internal representation.
